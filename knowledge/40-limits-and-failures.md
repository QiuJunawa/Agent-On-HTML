# 40 · 限制与故障

## 数据
- 清理站点数据 / 换浏览器 / 隐私模式 → IndexedDB 丢失。
- 内存模式关页面即丢；状态栏会提示。
- 导入备份会覆盖当前数据，导入前有确认；导出文件包含 API Key，别公开。
- 多标签页可能互相覆盖内存树。

## 能力
- 无真实 shell、无后台进程、无定时任务；页面关掉就停。
- run_js 无 DOM/网络/存储，8 秒超时。
- fetch_url 受 CORS；部分站点只能走代理。
- 图片理解取决于当前模型是否支持视觉；不支持时只能拿路径。

## 常见报错
- 400：消息角色/tool 配对不合法，或模型不支持某参数 → 检查 tool_calls 与 tool 响应是否成对。
- 401/403：Key 或 Token 无效/权限不足。
- 404：模型名/Base URL 错，或 Git 仓库路径不存在。
- 429：限流，降低并发/等待。
- CORS/Network：浏览器直连被拦，换服务商或配代理。
- 上下文超限：系统会临时收紧预算重试一次；仍失败就减少附件/长文件。

## 大文件
- read_file 单次上限 30k 字符，用行范围分段。
- 单文件 >200k 字符不进撤销栈。
