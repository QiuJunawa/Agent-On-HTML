# 90 · 使用指南

## 打开
- 本地：`python3 -m http.server 8080` 后打开 `/index-v2.html`；或直接双击。
- 线上：https://qiujunawa.github.io/Agent-On-HTML/index-v2.html

## 界面
- 左侧竖栏：对话 / 任务 / 插件；底部切主题、设置。
- 对话页：左文件树（文件/对话历史切换）、中间消息、右编辑器。
- 输入框上方可加附件；支持深浅主题、字体自定义。

## 设置
- **模型**：Base URL、API Key、模型名、温度、推理强度、输出上限。
- **Agent**：系统提示词、懒加载、超时、预算、记忆、标题生成、抓取代理。
- **工具**：勾选禁用。
- **Git 仓库**：平台/仓库/Token/分支，给 git_* 工具用。
- **界面**：主题、字号、界面字体、正文字体、紧凑布局、发送键。
- **数据**：导出/导入备份、清空。

## 插件
- 插件页 → 新建插件，写 JS，`AgentAPI.defineTool` 注册工具；默认禁用，启用前确认。
- 「官方插件库」可从 `qiujunawa.github.io/AOH_Plugins` 拉清单并安装，安装前会展示来源与代码摘录。
- 插件文件在 `/plugins/`，可随时禁用/删除。

## 知识库
- 内置在 `/knowledge/`，首次启动自动写入；可在编辑器里改。
