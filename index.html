隐私与密钥安全提示

    

      
本工具完全在浏览器本地运行（IndexedDB 存储），数据不会自动上传到任何服务器——除非你主动配置了云端同步（Gitee / WebDAV / Gist）或发起 AI API 请求。

      
但请务必注意：

      
    
        
  • API Key / Token 保存在本地，任何能打开这个页面的人都能通过浏览器开发者工具看到；私有仓库或"不公开"挡不住运行时暴露
    • 
        
  • 配置会随云端同步、备份导出、对话记录（/conversations/）一起被带走，截图、转发前注意检查
    • 
        
  • Gitee 上传为镜像同步：会自动删除云端存在但本地已删除的文件（手动上传和定时同步都生效）；仓库里不在同步路径下的文件不受影响
    • 
        
  • 配了 GitHub Codespaces 时，桥接端口一旦设为 Public，拿到地址和令牌的人就能在你的 Codespace 里执行命令；不用时请停掉 Codespace 或清空桥接令牌
    • 
        
  • 建议给 Key 设置消费/额度上限，按用途拆分 Key，定期轮换
    • 
        
  • 明文密钥不要提交进任何 Git 仓库（即使之后删除，历史里仍会保留）
    • 
      

      
详细说明见虚拟文件系统中的 /README.md 与 /config/README.md。
